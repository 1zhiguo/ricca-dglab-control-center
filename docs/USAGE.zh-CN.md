# 使用指南

[English](USAGE.md) · [返回 README](../README.zh-CN.md)

## 安装与连接

- Windows x64。完整解压便携 ZIP，保留 EXE 旁的 `_internal`，无需放进游戏目录。升级前正常退出旧客户端。
- 新手教程介绍总览、连接、强度、通道策略、按键录入；最后手动输入安全硬上限（0–100）。上限为 0 时禁用输出。
- “设备与游戏”选择手机能访问的局域网 IPv4，使用 DG-LAB 3.0 App 的 Socket 模式扫码。“连接不上？”可查看端口、VPN、网卡及 Wi-Fi 隔离排查建议。
- 默认自动寻找 `HolyKnightRicca.exe`。失败时可在软件内选择游戏 EXE；路径可含中文或日文，但游戏构建指纹仍须匹配。

## 输出规则

- “波形工作台 → 通道策略”为每个通道独立提供“战斗反馈”和“剧情／鉴赏”两大类。
- 战斗来源可选 HP、动作、两者结合或关闭。各事件分别设置强度、波形和时长。HP 分级按实际扣血量，不按最大血量百分比。
- 普通受击时长 0.1–3 秒，死亡最长 10 秒，破甲反馈最长 5 秒。持续捕获保持至挣脱，不提供时长设置；单独格挡不惩罚。
- 普通事件重叠不叠加强度：较强者接管，同强度刷新时长，较弱者忽略。A/B 分别判断。
- 本次生命首次检测到破甲后固定增幅 ×1.2，不再叠层；复活或重新进入游戏后重置，最终输出仍受硬上限约束。
- 死亡惩罚需要真实死亡证据，不能仅凭进入鉴赏场景触发。它优先于普通暂停，但**不能越过紧急归零和输出安全门**。连接、有效遥测、构建校验、教程完成和硬上限仍有效。

## 剧情、鉴赏与音频

- 每通道可选固定波形、循环队列、音频、固定＋音频、循环＋音频或关闭。已登记的剧情／鉴赏场景不必经过战斗死亡即可循环。
- “剧情信号”页编辑各通道队列，每段独立设置波形、强度和秒数。退出场景停止；暂停冻结进度，不在恢复时补播错过的片段。
- 音频采集须在“音频共感”页单独开启。系统回环检测所选输出设备的**全部声音**，不是单独识别人声；BGM 和其他程序也可能影响电平。不保存录音。
- 增益调整音频强度映射。“循环＋音频”可设置有效音频空隙中的最低强度，但不会越过增益静音、显式休止段、关闭采集、音频失效、暂停或硬上限。
- 未登记场景可能需要记录并明确登记。界面有场景名不等于设备已收到指令，须结合连接状态和诊断核对。

## 暂停与急停

新配置默认 **Ctrl+F12** 全局急停。在“个性化范围 → 全局急停键”点击“录入按键”，直接按单键或组合键即可；支持 Pause、F10 等单键，避免使用日常游戏操作键或打字键。Esc 取消录入。

录入或保存时会先急停。教程倒数第二页也可录入保存。升级保留原快捷键，注册或保存失败保留旧设置。

紧急归零清空两个通道并锁定输出；重复按键、重连和保存设置都不会恢复，须手动点“恢复输出”。F12 使用不拦截按键的监听，其他程序也可能响应；系统卡死或设备故障时不能保证快捷键有效。

## 配置与升级

配置：`%LOCALAPPDATA%\Ricca-x-DGlab\settings.json`

自定义波形：`%LOCALAPPDATA%\Ricca-x-DGlab\waveforms\`

升级不会覆盖这些用户文件。不要直接把个人配置作为软件默认值分发。保存使用原子替换，并保留上次有效备份；详见[配置迁移与日志（英文）](../DIAGNOSTICS.md#configuration-compatibility)。

语言切换只改变界面，不改变波形标识、检测哈希或通道设置。中英日界面支持与游戏版本兼容是两件事。
