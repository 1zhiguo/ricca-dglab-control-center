# Ricca × DG-LAB 1.1.0

## 中文

- 新增 DG-LAB V4，保留 V3；郊狼 Pulse 与负鼠振动可同时运行，独立选择、启停和保存配置。
- 负鼠独立官方振动波形、强度与剧情队列；强度支持 0–200、按 10 调整，并受软件与 App 通道上限限制。
- 简化连接页，统一两个工作台；新增左侧独立手动控制页，无游戏检测时也可显式控制已就绪设备。
- 更新游戏风格 HUD，显示两类设备的 A/B 数值与强度格，支持大小、位置和显示内容设置。
- 改进 V4 配件／静音提示、选择保持、异步输出、归零确认和断连处理；修复剧情队列关闭及双设备互相干扰问题。
- 保留已有郊狼配置；升级前退出旧版，完整解压新 ZIP。V4 选中设备后仍须核对配置并手动启用，重连不补播旧输出。

默认全局急停 Ctrl+F12，可自定义。软件上限不保证物理安全。V4 当前支持 COYOTE_030 与 OVC_1；不包含游戏本体，Windows 程序未签名。新镜像链接未提供前，请使用 GitHub Release。

## English

- DG-LAB V4 support alongside V3. Coyote electrical output and Opossum vibration run together with independent device selection, start/stop and settings.
- Dedicated official Opossum patterns, levels and story playlists; 0–200 in steps of 10, bounded by software and App channel caps.
- Simplified pairing page, matching workbenches and a dedicated manual-control tab for explicitly controlling ready devices without game detection.
- Restyled HUD with A/B numbers and level bars for both device types; configurable size, position and content.
- Improved accessory/mute diagnostics, retained selections, asynchronous output, acknowledged zeroing and disconnect handling. Fixed story-queue disabling and cross-device interference.
- Existing Coyote settings are retained. Quit the old app and extract the entire new ZIP. Verify and explicitly enable V4 devices; reconnecting does not replay old output.

Default global emergency stop: Ctrl+F12, customizable. Software caps do not guarantee physical safety. V4 currently supports COYOTE_030 and OVC_1. No game files included; Windows binaries are unsigned. Use GitHub Release until new mirror links are supplied.

## 日本語

- V3 を維持し、DG-LAB V4 に対応。郊狼の電気刺激とオポッサムの振動を、個別の設定・開始／停止で同時に使用できます。
- オポッサム専用の公式波形・強度・シナリオキューを追加。強度は 0–200、10 刻みで、ソフトと App の上限も適用します。
- 接続画面とワークベンチを整理。ゲーム検出なしでも準備済みデバイスを明示的に操作できる手動タブを追加。
- 両デバイスの A/B 数値・強度バーを表示する HUD。サイズ・位置・表示内容を変更可能。
- 配件・ミュート表示、選択維持、非同期送信、ゼロ化確認と切断処理を改善。シナリオキュー停止とデバイス間干渉を修正。
- 既存の郊狼設定を保持。旧版を終了し ZIP 全体を解凍してください。V4 は設定確認後に手動で有効化し、再接続時に以前の出力を再生しません。

緊急停止は標準 Ctrl+F12（変更可）。ソフト上限は身体の安全を保証しません。V4 対応は現在 COYOTE_030 / OVC_1。ゲーム本体は含まず、Windows 実行ファイルは未署名です。
